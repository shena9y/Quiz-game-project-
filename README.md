# ❓ Quiz Game

An interactive multiple-choice quiz game built with HTML, CSS, Bootstrap and vanilla JavaScript. Answer general-knowledge questions across a start screen, live quiz screen with progress bar, and a results screen showing your final score with a performance message — then restart and try to beat it.

## ✨ Features

- 🎬 **Start screen** with a "Start Quiz" entry point
- 📝 **Multiple-choice questions** rendered dynamically from a JS question bank
- 📊 **Live progress bar** and question counter (e.g. 3 / 10)
- 🏆 **Score tracking** with instant feedback on each answer
- 🎉 **Result screen** with final score and a tailored result message
- 🔄 **Restart button** to play again without reloading
- 📱 Responsive layout styled with Bootstrap + custom CSS

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** — custom styles
- **Bootstrap 5** — layout & components
- **Vanilla JavaScript** — quiz engine (`js/app.js`)

## 🚀 Getting Started

**Try it live:** [https://shena9y.github.io/Quiz-game-project-/](https://shena9y.github.io/Quiz-game-project-/) — no installation needed!

No build step needed:

```bash
git clone https://github.com/shena9y/Quiz-game-project-.git
cd Quiz-game-project-
```

Open `index.html` in your browser and hit **Start Quiz**. 🎮
